## 阶段2: 文档处理与 RAG 核心

### 2.1 document_loader.py
- parse_pdf(path) -> Document
- parse_markdown(path) -> Document
- parse_text(path) -> Document

### 2.2 text_splitter.py
- 递归字符切分 (RecursiveCharacterTextSplitter)
- Markdown 结构切分
- 语义切分 (按段落)

### 2.3 embedding_client.py
- OpenAI Embedding 客户端封装
- 批量向量生成
- 错误重试

### 2.4 vector_store.py
- Chroma 初始化 (持久化模式)
- add_documents(docs) -> 将文档片段存入向量库
- delete_document(doc_id) -> 删除文档及所有片段
- list_documents() -> 列出所有文档

### 2.5 retriever.py
- retrieve(query, top_k=5, score_threshold=0.7) -> List[Chunk]
- 混合检索（向量 + BM25）；MMR 去重为后续优化项
- 支持元数据过滤
- 格式化检索结果供 LLM 使用

## 阶段3: Agent 核心与工具

### 3.1 tools.py
- calculator: add/sub/mul/div/power
- get_current_time(timezone)
- web_search(query) - 模拟版 + 真实搜索接口
- query_docs(query) - 调用 retriever 搜索文档

### 3.2 agent.py [核心模块]
- Agent 类:
  - __init__(model_provider, system_prompt)
  - chat(user_input, history) -> AgentResponse
  - _decide_action(messages) -> Action (retrieve/tool/answer)
  - _execute_action(action) -> Result
  - _integrate_result(action_result) -> str
  - _format_prompt(question, context, tool_results) -> messages
- Agent 循环实现 (while not done)
- 流式响应支持

### 3.3 工具调用链路实现
1. 构建 messages (system + history + user)
2. 调用 LLM 生成响应
3. 解析响应: 有 tool_calls 则执行工具并返回步骤2
4. 无 tool_calls 则返回最终答案
